# MapReduce Shuffle 过程可视化

用前端技术把 MapReduce 的 Shuffle 过程做成**可交互、可拖拽、可调参**的动画。

核心特色：**它不是一段写死的关键帧动画，而是一个真实的确定性仿真器。**
动画里呈现的每一次溢写、每一次归并、每一条数据块的飞行，都是内核实时算出来的——
所以拖动进度条、调整参数后看到的因果链，和教科书上讲的完全一致。

## 快速开始

```bash
npm install
npm run dev      # 开发模式，打开 http://localhost:5180
```

部署/演示用构建产物：

```bash
npm run build
npm run preview  # 预览构建产物，打开 http://localhost:4180
```

## 一键启动脚本

不想记命令时，可直接用脚本一键拉起（自动安装依赖、构建、预览）：

```bash
bash start.sh              # 构建 + 预览，打开 http://localhost:4180
bash start.sh dev          # 开发模式，打开 http://localhost:5180
bash start.sh build        # 仅构建 dist/
bash start.sh preview-only # 直接预览已有 dist/（不重新构建）
bash start.sh check        # 运行内核正确性校验
```

Windows 用户直接双击 `start.bat` 即可（用法同上，参数为 `dev` / `build` / `preview-only` / `check`）。

> `npm run preview` 是长驻进程，若长时间使用后连接失败，重新执行该命令（或重跑脚本）即可
> （构建产物不受影响，`dist/` 目录始终可用）。

## 三个视图

| 视图 | 看什么 |
|---|---|
| **全局拓扑** | Map 端 → 网络传输区 → Reduce 端，数据块按分区着色飞向各自的 reducer |
| **Map 端特写** | 环形缓冲区水位 → 溢写（排序/Combiner/写盘）→ 合并大文件 + 分区索引 |
| **Reduce 端特写** | 多路有序片段 → K 路归并（带队首指针）→ 同 key 相邻 → 归组 reduce |

镜头默认跟随讲解节奏自动切换；手动点选后自动镜头让位，不再抢你的控制权。

## 核心设计

### 1. 颜色 = 目标 reducer，位置 = 来源 map

全片最重要的视觉约定。一旦建立，看中间乱序区时能立刻知道"这些块最终会去 0 号 reducer"。

### 2. 事件溯源的时间轴

```
SimConfig ──► 仿真内核 ──► 事件/状态时间轴 ──► 渲染层（Canvas + SVG）
```

内核只产出状态，渲染层只读状态。同一份 `SimConfig` 永远得到同一份时间轴，
因此回放、拖拽、参数对比全部是免费的。

### 3. 分层渲染

- **Canvas**：数据流、缓冲区、溢写文件、归并流（每帧重绘，不经过 React）
- **SVG**：拓扑骨架、交互热区、悬停高亮

两层共用 `src/render/layout.ts` 里的同一套坐标系，数据块会精确地飞向它要去的那个 reducer。

## 内核正确性

动画教错东西比没有动画更糟，所以内核有独立校验：

```bash
npm run check
```

覆盖 7 组场景配置，每组 14 项断言：

- 分区由 `hash(key) % numReduceTasks` 决定，同 key 必落同一 reducer
- value 守恒：所有输入 token 的 value 之和 == 所有输出的 value 之和
- K 路归并后相同 key 必然相邻（reduce 能分组的唯一前提）
- 合并文件按 `(分区, key)` 有序，索引与实际内容一致
- Combiner 吸收链自洽，能追溯到唯一存活者
- 时序：Map 提交 → 拉取 → 到达，顺序正确
- 溢写次数 == `ceil(记录数 / 缓冲区容量)`

## 交互

- 时间轴可拖拽，节拍标记直接对应讲解节点
- 倍速档位 0.05× / 0.1× / 0.2× / 0.25× / 0.5×（详见下方“播放速度”）
- 实时参数：Map/Reduce 数量、缓冲区容量、数据倾斜强度、每 Map 输入量
- 场景预设：标准 / 无 Combiner / 数据倾斜 / 频繁溢写
- 悬停 Reduce 框高亮该分区的全部数据
- **播放速度**：档位 `0.05× / 0.1× / 0.2× / 0.25× / 0.5×`，默认 `0.25×`。
  只保留讲课时用得上的慢速区间（去掉了 1× 及以上）。
  菜单里每档直接标注**实际播完全程的秒数**，不用自己换算：

  | 档位 | 全程约需 |
  |---|---|
  | 0.05× | 71 秒（可逐帧讲） |
  | 0.1× | 35 秒（边讲边指） |
  | 0.2× | 18 秒 |
  | 0.25× | 14 秒（默认） |
  | 0.5× | 7 秒（快速过一遍） |

- **侧栏可折叠**：点顶栏箭头或按 `D` 键，演示区从 1036px 扩到 1392px（+34%）。
  讲解内容不会消失，而是移到画布与时间轴之间的横条里 —— 位于画布之外，不遮挡任何画面。
  快捷键在输入框聚焦时不触发。
- **演示模式（全屏）**：点顶栏全屏按钮或按 `F` 键，隐藏顶栏、侧栏、图例、常规时间轴，
  动画铺满整个视口并同时请求系统全屏（浏览器拒绝时仍保留页内演示模式）。
  底部只留一条悬浮控制条（含当前节拍提示），**鼠标静止 2.6 秒后自动淡出**，移动即恢复。

  | 快捷键 | 作用 |
  |---|---|
  | `F` | 进入 / 退出演示模式 |
  | `Esc` | 退出演示模式（系统全屏下由浏览器接管） |
  | `Space` | 播放 / 暂停 |
  | `←` `→` | 步进 300ms |
  | `D` | 折叠 / 展开侧栏 |

## 目录结构

```
src/
  sim/
    engine.ts        仿真内核：Map 任务状态机、溢写、合并、K 路归并、分组
    rng.ts           确定性随机数 + FNV-1a 散列（模拟 HashPartitioner）
  render/
    layout.ts        共享坐标系（Canvas 与 SVG 对齐的依据）
    theme.ts         配色与排版令牌
    painter.ts       Canvas 渲染
    TopologyLayer.tsx SVG 拓扑层
  App.tsx            时间轴引擎、参数面板、讲解面板
scripts/
  check-sim.ts       内核正确性校验
  shots.ts           各阶段截图
  shots-fold.ts      折叠状态截图
  interact.ts        交互行为验证
  fold.ts            侧栏折叠验证
  present.ts         演示模式验证
  speed.ts           倍速档位验证
```

## 已实现 / 未实现

**已实现**：Hadoop MapReduce 主链路全流程、Combiner 开关与收益量化、
数据倾斜可视化、Map 端溢写三阶段（排序/合并/写盘）、索引生成、
K 路归并队首推进、分组归约、深浅两级镜头。

**未实现（架构已预留扩展点）**：Spark Shuffle 对比。
`SimConfig` 与内核的输出结构与引擎无关，后续可加一个 `engine: 'hadoop' | 'spark'`
分支复用全部渲染层。

## 技术栈

Vite 5 + React 18 + TypeScript（strict）+ Canvas 2D + SVG。
无 UI 框架、无动画库——时间轴用 rAF 直接驱动，渲染不经过 React，帧率稳定。
